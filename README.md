# Palmac downloads

Public signed downloads for Palmac, a native macOS toolbox for Turkish lawyers
and electronic-signature users. Source development remains private.

[Current supervised preview: Palmac 0.1.23 (27)](https://github.com/ardasevinc/palmac-downloads/releases/tag/v0.1.23).
[Download the complete test kit](https://github.com/ardasevinc/palmac-downloads/releases/download/v0.1.23/Palmac-Sena-Test-0.1.23-27.zip),
or choose the standalone DMG in Releases.

Install manually once. Existing build 25 users can choose **Palmac → Check for
Updates…**. The signed update feed is live; tamper rejection, cancellation,
25-to27 replacement/relaunch, older-version refusal and offline errors were
tested on macOS 26.6.2 and 27.2 using isolated copies. Download, install and
relaunch remain your choices. Separate portable CLI copies and vendor middleware
are not replaced by the app updater.

Update feed: https://raw.githubusercontent.com/ardasevinc/palmac-downloads/main/appcast.xml

Apple Silicon and macOS 26 or later are required. Apps are Developer ID signed,
Apple notarized and stapled; update archives and feeds carry separate signatures.
These are supervised previews. Real-card activation and authenticated portal
signing still require testing with the card owner. Public availability does not
establish hardware/provider/portal compatibility.
