# Palmac downloads

Public signed application downloads and update metadata for Palmac, a native
macOS toolbox for Turkish lawyers and electronic-signature users.

Source development is private. [Palmac 0.1.21 (25) supervised preview](https://github.com/ardasevinc/palmac-downloads/releases/tag/v0.1.21) is available.

[Download the test kit](https://github.com/ardasevinc/palmac-downloads/releases/download/v0.1.21/Palmac-Sena-Test-0.1.21-25.zip), or choose the standalone DMG in Releases.

The app contains the updater integration, but its signed feed and successful
end-to-end update test are pending. Use the manual download for this preview.

Update feed: https://raw.githubusercontent.com/ardasevinc/palmac-downloads/main/appcast.xml

Release archives will be published under GitHub Releases. Update archives and
metadata are signed; publishing a file here does not establish real-card or
portal compatibility. macOS 26 or later on Apple Silicon is required.
